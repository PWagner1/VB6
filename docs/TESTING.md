## Reproduce

```sh
npm run build
npm test
python tools/browser-tests.py
python tools/browser-parity-tests.py
npm run test:visual:goldens
npm run test:features
npm run test:recovery
npm run test:finalization
npm run test:boundaries
```

Node.js 22+ is required. Browser suites require Python, Playwright, Pillow and Chromium. The measured environment was Node 22.16.0 and Chromium 144.0.7559.96. The build has no npm package dependencies. Visual exact comparisons require the same browser/font environment; ordinary visual/interaction tests are separate from native appearance certification. Parallel suites use isolated browser contexts and separate report files.

## Source archive and SDK verification

`python tools/package-release.py --out <release-directory> --git-bundle` creates source manifest, built app, browser distribution, independent runtime SDK, eleven standalone examples, visual evidence and Git bundle.

`python tools/verify-release.py --release-dir <release-directory> --work <new-empty-directory> --version 0.6.0 --check-goldens` extracts the actual source ZIP, validates every listed hash and rejects font/path violations, rebuilds all generated files and compares their bytes, checks the separately delivered standalone HTML, reruns Node and all seven browser suites, imports the isolated SDK, restores the Git bundle/main/tag and checks archive CRCs/checksums. The external `Archive-Verification` report records that separate attempt and outcome; this document's integrated totals do not replace it.

The SDK smoke test additionally checks native resource strings and byte-identical .res roundtrip, independent typed resource arrays and DefInt source execution. Source-built test results are separate from a native VB6 differential oracle.

## Visual review and launch boundaries

All 34 current implementation screenshot states were reviewed, including classic/standard/high-contrast, split editor, property dialogs, controls, narrow viewport and DPR2. The intentional changes from 0.5 are documented in reports/visual-review-06.json. Additional Resource Editor, Evaluation and MDI captures are included. None are native Microsoft VB6 reference pixels. Hardware/font/DPI differences and missing native state surfaces prevent an exact-native-parity claim.

Six separate launch probes attempted file and localhost HTTP navigation of standalone IDE, split IDE and standalone workbench. **All six were blocked with ERR_BLOCKED_BY_ADMINISTRATOR before application startup; zero passed.** See reports/launch-probe.json and reports/release-06/launch-probes.log. They are not included in successful behavioral counts. Tests load the emitted HTML using inline Chromium loading and exercise real exported/downloaded bytes.

Direct launch and real-origin persistence are not certified. Canvas2D is exercised; hardware WebGPU, Firefox/Safari, physical mobile devices, complete native IME, arbitrary locale/font installations and screen readers remain unverified. Automatic watches intentionally do not execute source code; explicit evaluation has cooperative budgets, and live editing intentionally rejects unsupported transformations. See COMPATIBILITY.md.
